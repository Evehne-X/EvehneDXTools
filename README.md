# EvehneDXTools for 3DXChat official
The Evehne's 3DXChat Tools

Actual version 26.6.15

## WORLD File Features :
- .WORLD Optimisations (gain 20-30% of size)
- .WORLD Dupes remover
- .WORLD Groups disolver
- .WORLD Reports & Analysis
- .WORLD Global mover
- Create color palette from a .WORLD (JSON, CSV, ACO, GPL)

## Builder / Dressing Features :
- Manage Builder/Dressing color palette
- Build your palette with Gradient generator, RGB/RGBHex/HSL values
- Reorder by insert empty case / drag & drop existant color
- import/export from 3DXPal, JSON, ACO, GPL
- Hot loading (without game reloading, just relaunch build mode or dressing)
